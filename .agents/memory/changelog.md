### Sprint: Claude Code Engine v2 Port

* **Accomplishment**: Rebuilt the Epoch engine as native Claude Code constructs on branch `claude-code-v2`. Added `CLAUDE.md` (Startup SOP, memory map, command index), `.claude/rules/core-directives.md`, and skills `init`, `plan`, `checkpoint`, `milestone`, `scaffold-module` under `.claude/skills/`. Added a `SessionStart` hook in `.claude/settings.json`. Deleted `adk-agent-template/`, `scripts/create-agent.py`, `.agents/{rules,workflows,skills}`, and untracked live MCP configs (sanitized example kept). Replaced the bootstrapper with `scripts/create-workspace.py`, rebuilt `scripts/sync-templates.py` for the new layout (idempotent), added `protocol_version: 2.0` frontmatter and a `## Verification Commands` section to memory files, rewrote `README.md` and `EVALUATION.md` (now six phases including milestone capture), and wired `markdownlint-cli2` as this repo's verification command.
* **Decisions**: State (`.agents/memory/`) stays harness-neutral; only the engine is Claude Code-specific so future adapters stay thin. `/checkpoint` verification is data-driven from `context.md` rather than hardcoded per stack. The project `init` skill intentionally replaces Claude Code's bundled `/init` (documented override behavior). The `SessionStart` hook is kept as belt-and-suspenders alongside `CLAUDE.md`; it omits a matcher so it fires on startup, resume, clear, and compact. Rotated pre-v2 changelog entries into `.agents/memory/archive/changelog-v1.md`.

### Sprint: Claude Code Plugin Packaging (v2.1)

* **Accomplishment**: Repackaged the engine as the `epoch` plugin under `plugin/` (manifest 2.1.0) on branch `plugin-v2.1`. Skills moved from `template/.claude/skills/` to `plugin/skills/`; `init` and `plan` now self-bootstrap a blank `.agents/memory/` and offer a `CLAUDE.md` snippet and `git init`; `checkpoint` and `milestone` refuse to run without memory. Added a conditional `SessionStart` hook (`plugin/hooks/hooks.json`) that is provably silent outside Epoch workspaces. `scripts/sync-templates.py` now propagates `plugin/` -> `template/` -> root and renders the bundled templates into a generated section of the bootstrap skills; idempotent. Self-hosted marketplace at `.claude-plugin/marketplace.json` validated with `--strict` and installed from a clean state (`claude plugin marketplace add`, `claude plugin install epoch@epoch`). Four-case `claude plugin eval` suite under `plugin/evals/`. README and EVALUATION rewritten for the plugin-first path (EVALUATION Phase 7: fresh-machine flow). All commands documented in namespaced `/epoch:*` form with a per-repo un-prefixed note.
* **Decisions**: **Bootstrap mechanism**: `${CLAUDE_PLUGIN_ROOT}` resolves inside skill bodies and `!` injections, but headless/sandboxed sessions deny `Read`, `cat`, and `cp` on any file under the plugin directory (verified with probe skills), so the templates are embedded verbatim in `init`/`plan` between `<!-- epoch:templates:begin/end -->` markers, generated by the sync script from `plugin/templates/`; the skills write them with the `Write` tool. `plugin/` is the only hand-maintained engine source; `template/` and the root `.claude/skills/` are generated and committed for the copy-a-folder and dogfood paths. `SessionStart` hook omits `matcher` and uses a POSIX one-liner with no jq. Eval prompts pre-answer the checkpoint's next-session question so the failing-verification case can reach step 4 in a single headless turn.
* **Eval results (2026-09-20, default 3 runs per arm, with/without baseline, `socat` installed)**: all four cases pass at threshold 1.0. `cold-init` WITH 1.00 / W/OUT 0.00 / Δ +1.00. `milestone-discipline` 1.00 / 0.50 / +0.50. `checkpoint-verification` 1.00 / 0.62 / +0.38. `state-restoration` 1.00 / 1.00 / 0.00 (the no-plugin baseline also reads the memory files once a realistic codebase is present, so this case guards behavior but does not discriminate). Two test-layer fixes were needed first: `cold-init` graders used brace globs and `tool_used: Skill` (which never fires for slash invocations), and the `milestone-discipline` fixture contained no code for the claimed milestone, so Claude correctly refused to record it. Total cost of the recorded runs: about $3.20.
